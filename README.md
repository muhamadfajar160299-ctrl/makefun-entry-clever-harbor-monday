A one-star review of Monday written as if Monday were a restaurant: the waiter seats you at Monday, serves cold coffee, then bills you for the entire week. `main.py` (stdlib only) writes the single 18-word line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
